# 田野浜 VR

公開・今後の更新先: https://ob198-cpu.github.io/dassyutu/tanohama/vr/

このディレクトリだけを更新し、GitHub Pages の反映を確認する。公開前にPCで画面遷移・文字入力・保存復帰・4章とボス・無音の動作を検査する。Quest実機の表示・操作・性能は実機で別途確認する。

`tanohamaVRStateV1` を含む旧VRや本編の保存データは消去せず、この版の独立した保存キーを使用する。別オリジンの保存データは自動的に移行されない。映像・音声の既定状態は無音。

KayKit素材の条件と出典は `assets/kaykit/LICENSE.txt` と `assets/kaykit/SOURCE.txt` を参照する。第三者のTripo公開モデルと取得元不明の魔導書は公開再配布条件を確認できないため、この公開版には含めていない。
